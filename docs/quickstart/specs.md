# 硬件参数

## 技术规格总览

| 参数类别 | 参数项 | 规格 |
|:---------|:-------|:-----|
| **处理器** | 芯片型号 | 全志 H618，四核 ARM Cortex-A53，最高 1.5GHz |
| | GPU | ARM Mali-G31 MP2 |
| **内存** | 容量 | 1GB / 2GB / 4GB LPDDR4（可选） |
| | 最高配置 | 4GB LPDDR4 |
| **存储** | 板载存储 | 8GB / 16GB / 32GB / 64GB eMMC 5.1（可选） |
| | 最高板载 | 64GB eMMC 5.1 |
| | 外部扩展 | USB 2.0 外接 U 盘、移动硬盘 |
| | 存储卡扩展 | MicroSD (TF) 卡槽，最高支持 512GB |
| **网络** | 有线 | RJ45 × 1，10/100Mbps 自适应 |
| | Wi-Fi | Wi-Fi 5 (802.11ac)，2.4G/5G 双频 |
| | 蓝牙 | Bluetooth 5.0 |
| **接口** | USB | USB 2.0 Type-A × 2 |
| | 视频输出 | HDMI 2.0a × 1（支持 4K@60Hz） |
| | 音频 | 3.5mm 复合音频接口 × 1 |
| | TF卡槽 | MicroSD 卡槽 × 1 |
| **电源** | 输入 | DC 5V/3A（Type-C 供电） |
| | 典型功耗 | 5W（待机）、10W（满载） |
| **物理参数** | 尺寸 | 110mm × 75mm × 28mm |
| | 重量 | 约 180g |
| | 散热 | 无风扇被动散热（散热片+格栅） |
| **环境** | 工作温度 | 0°C ~ 50°C |
| | 存储温度 | -20°C ~ 65°C |
| | 湿度 | 5% ~ 95%（无冷凝） |

## 指示灯

设备仅有一个蓝色电源指示灯：

| 状态 | 含义 |
|------|------|
| :material-power: 蓝色常亮 | 设备已通电，系统正常运行 |
| :material-power: 蓝色闪烁 | 系统启动中（约 30 秒） |
| :material-power: 熄灭 | 设备未通电 |

### 预装 AI 智能体框架

AIEdge 出厂预装四款核心软件，**开箱即用**：

| 软件 | 版本 | 定位 | 核心能力 |
|------|:----:|------|----------|
| **Mihomo (Clash)** | latest | 网络代理服务 | 透明代理、订阅更新、规则分流，保障 API 链路畅通 |
| **OpenClaw** | latest | 多通道AI智能体网关 | 多平台消息接入、多智能体路由、技能市场、定时任务 |
| **Hermes Agent** | latest | 终端原生自治AI代理 | 持久记忆、自进化技能、21+平台消息网关、Any模型适配 |
| **Claude Code** | latest | AI编程助手CLI | 代码生成/审查/重构、项目级上下文理解、Git工作流集成 |

!!! info "运行原理"
    AIEdge **不在本地运行大模型**。所有 AI 智能体软件通过 API 调用云端 LLM 服务（如 Anthropic Claude、OpenAI GPT、DeepSeek、OpenRouter 等）。设备本身作为智能体运行时 + API 网关 + 消息中枢，持久运行在您的局域网中。
