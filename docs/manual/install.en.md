# Installation Guide

## Environment Requirements

### Conditions

| Condition | Requirement |
|--------|------|
| Temperature | 0°C ~ 50°C (recommended 15°C ~ 30°C) |
| Humidity | 5% ~ 95% (non-condensing, recommended 40% ~ 60%) |
| Altitude | ≤ 3000m |
| Dust | Office/server room environment, no significant dust |

### Space Requirements

- Keep **≥ 5cm** clearance around all sides of the device
- Keep **≥ 10cm** clearance above the device (do not stack items on top)
- Place on a **stable, non-slip** surface

### Power Requirements

- Voltage: USB Type-C 5V DC (included with select models)
- Power: minimum 10W
- Use the included adapter whenever possible

---

## Installation Steps

### Step 1: Choose Location

- [ ] Near Ethernet port and power outlet
- [ ] Well-ventilated
- [ ] No direct sunlight or heat sources
- [ ] Stable, level surface

### Step 2: Connect the Device

Connect in the following order (**follow the sequence strictly**):

```
  ┌──────────────────────────────────────┐
  │  1. Ethernet → RJ45 port             │ Connect data cables first
  │  2. HDMI    → HDMI port (optional)   │ Then display
  │  3. USB     → USB port (optional)    │ Then peripherals
  │  4. Power   → Type-C port (last)     │ Power last
  └──────────────────────────────────────┘
```

!!! danger "Connection Order"
    **Always connect all data cables first; connect power last!** Hot-plugging may damage the ports.

### Step 3: Cable Management

- Use cable ties to organize wiring
- Leave adequate slack to avoid pulling on connectors

### Step 4: Power-On Verification

| Check Item | Standard |
|--------|------|
| Blue LED | Blinking → Solid (within 30 seconds) |
| Unusual noise | None (passive cooling, completely silent) |

---

## Safety Checklist

- [ ] Device placed on a stable surface, no wobbling
- [ ] Type-C power cable properly connected, no damage (included with select models)
- [ ] Ethernet cable RJ45 clip locked in, doesn't come loose with a gentle tug
- [ ] 5cm clearance maintained around the device
- [ ] Kept away from water, beverages, and chemicals
- [ ] LED indicator shows normal (solid blue)
- [ ] Router DHCP service is enabled

---

## Prohibited Actions

!!! danger "Strictly Prohibited"
    - :material-close-circle: **Do not** cover the device with cloth, paper, or other obstructions
    - :material-close-circle: **Do not** use in humid environments or outdoors
    - :material-close-circle: **Do not** disassemble the device casing
    - :material-close-circle: **Do not** use non-original power adapters
    - :material-close-circle: **Do not** move or shake the device while it is running
    - :material-close-circle: **Do not** block the ventilation grilles
