# 开机与关机

## 开机流程

### 正常开机

AIEdge 设备**通电即开机**，无独立电源开关按钮。

```
接通电源 → 自动开机 → 系统引导 → 服务就绪
  (0s)      (0~2s)    (20~30s)    (30~60s)
```

### 开机指示灯变化

设备仅有一个蓝色电源指示灯：

| 时间节点 | 指示灯 | 说明 |
|:---------|:-------|:-----|
| 通电瞬间 | 🔵 蓝闪烁 | 硬件上电 |
| 5 秒后 | 🔵 蓝闪烁 | Bootloader |
| 20 秒后 | 🔵 蓝慢闪 | Linux 内核启动 |
| 30 秒后 | 🔵 蓝常亮 | 系统就绪 |
| 45 秒后 | 🔵 蓝常亮 | 智能体服务就绪 |

!!! success "开机完成"
    当**蓝色指示灯变为常亮**，且能通过 SSH 登录设备时，说明开机完成。

## 关机流程

### 正常关机（推荐）

!!! warning "重要"
    请**务必通过命令行进行软关机**，不可直接拔电源！

#### SSH 登录后关机

```bash
# SSH 登录设备
ssh root@[设备IP]

# 执行关机命令
shutdown -h now
```

等待蓝色指示灯熄灭后（约 10 秒），断开电源适配器。

### 强制关机（仅限异常情况）

!!! danger "注意事项"
    强制关机可能导致**数据丢失**或**文件系统损坏**。仅在下述情况下使用：

    - 系统无响应超过 5 分钟
    - 无法通过 SSH 访问
    - 设备异常发热且有焦味

强制关机操作：

1. 长按设备**复位按钮** 10 秒以上
2. 或直接拔掉 Type-C 电源线（部分型号提供）

强制关机后重新通电，设备会**自动执行文件系统检查**，启动时间可能延长至 2-3 分钟。

---

## 重启流程

### 软重启（推荐）

```bash
# SSH 登录后执行
shutdown -r now
# 或
reboot
```

重启过程约需 **40-60 秒**。
