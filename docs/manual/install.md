# 设备安装规范

## 安装环境要求

### 环境条件

| 条件项 | 要求 |
|--------|------|
| 温度 | 0°C ~ 50°C（推荐 15°C ~ 30°C） |
| 湿度 | 5% ~ 95%（无冷凝，推荐 40% ~ 60%） |
| 海拔 | ≤ 3000m |
| 灰尘 | 办公/机房环境，无明显粉尘 |

### 空间要求

- 设备四周保留 **≥ 5cm** 散热空间
- 设备上方 **≥ 10cm** 空间（勿堆叠物品）
- 放置在**平稳、不易滑动**的表面

### 电力要求

- 电压：USB Type-C 5V DC（部分型号提供）
- 功率：最低 10W
- 建议使用随附适配器

---

## 安装步骤

### 第一步：规划位置

- [ ] 靠近网口和电源插座
- [ ] 通风条件良好
- [ ] 无阳光直射、无热源
- [ ] 桌面平稳不摇晃

### 第二步：连接设备

按以下顺序连接（**严格按顺序操作**）：

```
  ┌──────────────────────────────────────┐
  │  1. 网线  →  RJ45 口                 │ 先接网线
  │  2. HDMI  →  HDMI 口（可选）         │ 再接显示
  │  3. USB   →  USB 口（可选）          │ 再接外设
  │  4. 电源  →  Type-C 口（最后）       │ 最后通电
  └──────────────────────────────────────┘
```

!!! danger "连接顺序"
    **必须先连接所有数据线缆，最后再接通电源！** 热插拔可能导致接口损坏。

### 第三步：理线

- 使用线缆扎带整理走线
- 预留适当长度，避免拉扯接口

### 第四步：通电验证

| 验证项 | 标准 |
|--------|------|
| 蓝色指示灯 | 闪烁 → 常亮（30秒内） |
| 异常声响 | 无（被动散热，完全静音） |

---

## 安全检查清单

- [ ] 设备放置平稳，不晃动
- [ ] Type-C 电源线正确连接，无破损（部分型号提供）
- [ ] 网线水晶头卡紧，轻拉不脱落
- [ ] 设备周围 5cm 内无遮挡物
- [ ] 远离水源、饮料、化学物品
- [ ] 指示灯显示正常（蓝色常亮）
- [ ] 路由器 DHCP 服务已开启

---

## 禁止事项

!!! danger "严禁"
    - :material-close-circle: **禁止**在设备上覆盖布料、纸张等遮蔽物
    - :material-close-circle: **禁止**在潮湿环境或户外使用
    - :material-close-circle: **禁止**自行拆解设备外壳
    - :material-close-circle: **禁止**使用非原装电源适配器
    - :material-close-circle: **禁止**在设备运行时移动或摇晃设备
    - :material-close-circle: **禁止**堵塞散热格栅
